# Project Portfolio

## Description
This project is just for showcasing frontend

## Installation
1. Clone the repository: `git clone https://github.com/abhinavjha0239/project-portfolio.git`
2. Navigate to the project directory: `cd project-portfolio`
3. Open `index.html` in your browser to view the project.

## Usage
This project is a frontend showcase. You can view the different frontend components and designs by navigating through the pages.
